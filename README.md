# Answer

หน้าเว็บรวมเฉลยแบบฝึกหัดสำหรับ GitHub Pages

## การใช้งาน

1. เปิด `https://songsith305-beep.github.io/Answer/`
2. กด **จัดการไฟล์**
3. ใส่ GitHub fine-grained token ที่จำกัดเฉพาะ repository `Answer` และให้สิทธิ์ **Contents: Read and write**
4. อัปโหลดไฟล์ `.html` แล้วระบบจะสร้างปุ่มให้โดยอัตโนมัติ

ในหน้าจัดการสามารถเปลี่ยนชื่อปุ่ม อัปโหลดไฟล์ใหม่ทับ URL เดิม หรือลบทั้งปุ่มและไฟล์ออกจาก GitHub ได้

> ระบบไม่บันทึก token ลงใน repository, localStorage หรือ sessionStorage เมื่อรีเฟรชหน้าจะต้องใส่ token ใหม่
