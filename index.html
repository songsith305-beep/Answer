    วิธีใช้: อัปโหลดไฟล์ .html ตัวจริงขึ้น GitHub เอง (ไว้โฟลเดอร์เดียวกับ index.html) แล้วค่อยเพิ่มลิงก์ที่นี่ให้ชื่อไฟล์ตรงกัน ปุ่มจะพาไปเปิดไฟล์จริงบน GitHub Pages โดยตรง

    ทุกครั้งที่เพิ่ม/ลบ/เปลี่ยนชื่อลิงก์ ให้กดปุ่มนี้เพื่อดาวน์โหลด index.html ตัวล่าสุด แล้วนำไปอัปโหลดทับไฟล์เดิมบน GitHub (ลากไฟล์ชื่อเดิมไปวางที่ Add file > Upload files ก็เขียนทับให้เอง)
