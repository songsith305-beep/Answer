เฉลยแบบฝึกหัด

รายการนี้อัปเดตอัตโนมัติจากไฟล์บน GitHub

ไม่ต้องแก้ไฟล์นี้อีกแล้ว — หน้านี้จะไปเช็กไฟล์ .html บน GitHub ให้เองทุกครั้งที่มีคนเปิด
  1. อยากเพิ่มเฉลย: อัปโหลดไฟล์ .html เข้าโฟลเดอร์เดียวกับ index.html บน GitHub
  2. อยากลบเฉลย: ลบไฟล์นั้นออกจาก GitHub
  3. อยากเปลี่ยนชื่อปุ่ม: เปลี่ยนชื่อไฟล์บน GitHub (rename)
  4. อยากอัปเดตเนื้อหา: อัปโหลดไฟล์ชื่อเดิมทับของเดิม
